# Nobody Trusts Your AI — ProductCamp RTP deck

A single-file HTML presentation by Rajiv Kaul (Intelligaia).

- **View:** open `index.html` in a browser, or run `python3 -m http.server 8765` and visit `http://127.0.0.1:8765`.
- **Present:** use → / ← or a clicker. On the process slides (14–18), each press walks through the numbered pointers before moving to the next slide.
- **Edit:** see [AGENTS.md](AGENTS.md). Slides 14–18 (the five processes) and 20 (Key Takeaways) come from `deck-src/`. Edit the JSON and screen files there, then run `python3 deck-src/build.py`.
